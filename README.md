# Shanwei video asset workspace

This repository is being used to collect openly licensed reference material for the short video **《向海而生 · 我的家乡汕尾》**.

The automated workflow downloads source images from Wikimedia Commons, keeps the originals, and creates 1920×1080 reference crops for Gemini / video editing.

See `shanwei-video-assets/ATTRIBUTION.md` for authors, source pages, and licenses.
